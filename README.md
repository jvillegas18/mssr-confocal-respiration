# mssr-confocal-respiration
# Confocal Microscopy and Super-Resolution (MSSR) Pipeline for the Quantification of Respiration in Marine Prokaryoplankton

This repository contains the computational workflow developed for processing confocal images, applying **Mean-Shift Super Resolution (MSSR)**, and automated statistical modeling. This pipeline constitutes the methodological basis of the manuscript titled:

> **"From artifact to quantitative signature: the INT-formazan crystal as an optical modulator of nucleic acid fluorescence in marine prokaryoplankton, characterized by confocal microscopy, computational super-resolution MSSR, and STED nanoscopy"**

## 📊 Scientific Purpose
This tool enables automated quantification of prokaryotic respiration rate at the single-cell scale via the three-dimensional optical signature generated by the deposition of INT-formazan crystals and their interaction with nucleic acid fluorophores (DAPI and SYBR Green I).

## 📁 Repository Structure
- `01_PyImageJ_LIF_Extraction.ipynb`: Notebook for the automated reading of native Leica microscopy files (`.lif`).
- `02_MSSR_Pipeline_Full.ipynb`: Consolidated multi-session pipeline. Automates cell segmentation and MSSR super-resolution processing.
- `requirements.txt`: Dependencies file with the required Python libraries.

**How to run the pipeline in Google Colab using this data:**
1. Open the Google Drive link above.
2. Click on the folder name at the top and select **"Add shortcut to Drive"**. Place it in your main drive (`My Drive`).
3. When running the notebooks in Google Colab, the pipeline will automatically detect the shared folder and process the data immediately.
